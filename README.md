# Falange - Controle de Paletes

Sistema simples para registrar e localizar paletes nos corredores da loja.

## Funcionalidades

- 60 corredores
- Adicionar, editar e remover mercadorias
- Pesquisa por número do corredor ou nome da mercadoria
- Dados salvos no celular (LocalStorage)
- Funciona offline
- Otimizado para uso no celular

## Como usar

1. Abra o `index.html` no navegador (ou publique no GitHub Pages)
2. Use a barra de pesquisa ou clique em um corredor
3. Adicione as mercadorias

## Publicar no GitHub Pages

1. Crie um repositório novo (ex: `Falange`)
2. Faça upload destes arquivos
